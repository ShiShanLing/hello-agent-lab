# Agent 主站长期开发规则

本文件适用于单独打开 `frontend/` 的 Codex 及其他开发工具；同时继续遵守仓库根目录的安全发布规则。

1. 禁止自动切换、创建或重命名 Git 分支，也不得自行进入 detached HEAD 或其他 worktree。任何分支变化必须先说明原因和目标分支，得到用户明确同意。
2. 打包、部署或发布必须依次完成：确认当前分支 → 测试与构建 → 检查并提交源码和 `dist/` → 推送当前分支到 GitHub → 确认远程提交一致 → 使用仓库发布脚本发布 → 线上验收。推送失败时禁止发布。
3. Git 提交标题与正文、GitHub PR 标题与说明、Release 标题与更新说明必须使用中文；命令、路径和代码标识符可以保留原文。
4. `dist/` 不得加入 `.gitignore`。正式构建与发布时必须检查并提交对应产物，确保 GitHub 能追溯线上版本。
5. 只提交本次相关修改，保留用户已有改动；不得提交密钥、数据库、上传文件、缓存或日志。
6. 完成后报告当前分支、提交号、GitHub 远程分支和线上验收结果。
